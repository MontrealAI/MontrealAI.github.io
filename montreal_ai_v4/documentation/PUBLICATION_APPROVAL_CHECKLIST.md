# Public publication approval checklist

- [ ] Publisher and rightsholders identified
- [ ] French and English parity reviewed
- [ ] Material claims classified and supported
- [ ] No misleading general impression from text or imagery
- [ ] No token sale, investment solicitation or return promise
- [ ] No payment, custody, remittance, exchange or sensitive transaction
- [ ] No personal, privileged, customer, classified or secret material
- [ ] No private Publisher Vault or signing material
- [ ] AI-assisted media disclosed where appropriate
- [ ] Status and limitations visible
- [ ] External links and third-party dependencies reviewed
- [ ] Static and browser QA passed
- [ ] Manifest and checksums regenerated
- [ ] Independent Québec counsel sign-off obtained before live commercialization
