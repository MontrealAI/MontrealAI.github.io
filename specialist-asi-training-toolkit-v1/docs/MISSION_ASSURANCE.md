# Mission Compiler Assurance

The Mission-to-Gym Compiler is not complete when JSON parses. A production mission must also be diagnosable.

The assurance report checks:

- mission feature bounds and positive horizon;
- action-space breadth;
- terminal and truncation reachability;
- dynamic observation coverage;
- constraint-triggering cases;
- expert action support;
- split commitment overlap;
- verifier strength;
- world-model basis risk;
- readiness for Formation and Fresh Proof.

A blocking finding prevents autonomous formation. A warning requires a named mitigation, proof reserve or narrower mission.
