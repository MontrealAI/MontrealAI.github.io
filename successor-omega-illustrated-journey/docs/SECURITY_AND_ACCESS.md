# Security and Access

Access is available to the current direct owner of one exact `*.club.agi.eth` name or the current direct holder of at least 1,000,000 official AGIALPHA on Ethereum Mainnet.

Balances are not aggregated. Resolver records, former ownership and delegation do not count as direct AGI Club ownership.

The site requests wallet connection, Ethereum Mainnet and a readable signature. It never requests approval, transfer, payment, staking, locking, burning, deposit, custody or transaction authority.

Every protected file is encrypted with AES-256-GCM. The public repository contains ciphertext and hashes; the content key remains a Worker secret. The browser decrypts and verifies locally after current eligibility is checked.

A downloaded file cannot be technically revoked after delivery. Access is not identity assurance, competence, corporate mandate, Chronicle admission or Successor Ω authority.
