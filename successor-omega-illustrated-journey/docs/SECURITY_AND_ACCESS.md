# Security and Access

Access is available to the current direct owner of one exact `*.club.agi.eth` name or the current direct holder of at least 1,000,000 official AGIALPHA on Ethereum Mainnet.

The browser performs current reads through the connected wallet provider. Resolver records, former ownership, delegation and balances held by another address do not qualify. Balances are not aggregated.

The site asks only for wallet connection, Ethereum Mainnet and a readable signature. It never requests approval, transfer, payment, staking, locking, burning, deposit, custody or transaction authority.

The session expires, revalidates periodically and relocks when the account or network changes. Access is not identity assurance, competence, corporate mandate, Chronicle admission, Specialist ASI or Successor Ω authority.

GitHub Pages is public static hosting. The client-side gate mirrors the working Specialist ASI Training Toolkit and cannot provide server-side confidentiality. Once a file is opened, it cannot be technically revoked.
