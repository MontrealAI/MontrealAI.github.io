# Sources and Methodology — GoalOS Singularity Office Ω v2.0.0-SO2

The embedded signed source pack is an official-source snapshot verified on 26 July 2026. It includes primary material from NIST, the European Commission, W3C, OWASP, the OQLF, the Commission d’accès à l’information du Québec, the International Energy Agency and OpenAI.

## Method

1. Record the official source, authority, verification date and decision implication.
2. Sign the canonical source pack using the publisher's P-256 key.
3. Verify the signature in the browser before treating the pack as publisher-issued.
4. Treat the snapshot as time-bounded; reverify current source text before consequential action.
5. Map source changes to affected claims, missions, authority envelopes and transaction gates.
6. Preserve provenance through Evidence Dockets and Chronicle records.

The public application does not silently refresh from the internet. A publisher may issue a newly signed source pack through the private Source Pack Studio. A protected deployment may implement an approved refresh pipeline with source snapshots, review and incident controls.
