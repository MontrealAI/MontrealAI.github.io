# GoalOS UVSI2 v7.0.0

Upload this directory to the root of a GitHub repository and enable GitHub Pages.

- `index.html` is the strict dual-access application.
- `config.js` contains public configuration only.
- `GoalOS_UVSI2_v7_STANDALONE.html` is the one-file preservation edition.
- `docs/DEPLOYMENT_GUIDE.html` provides complete instructions.

Never place API keys in this directory. Configure secure AI through the separate backend package.
