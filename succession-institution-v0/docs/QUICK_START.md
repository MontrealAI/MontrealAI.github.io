# Three-minute quick start

1. Download and unzip `GoalOS_UVSI2_v7_GitHub_Pages.zip`.
2. Upload its contents to a GitHub repository.
3. In GitHub: **Settings → Pages → GitHub Actions**. The included workflow deploys the root directory.
4. Open the deployed page in a wallet-enabled browser.
5. Choose **AGI Club Owner Access** or **AGIALPHA Balance-Qualified Access**.
6. Sign the domain-bound access receipt. The signature creates no transaction or authority.
7. Start in **Command Center**, then select **Navigator Ω** or **Mission**.
8. Use the offline compiler immediately. Configure the optional secure AI backend in **AI Studio** later.

For confidential real missions, use a protected server deployment rather than storing sensitive data in a public-static browser application.
