# GoalOS v8.8.0-UVSI3 — Five-minute quick start

## Local executable route

1. Unzip the Local Toolkit package.
2. Run `START_MAC.command`, `START_WINDOWS.bat` or `START_LINUX.sh`.
3. Open `http://127.0.0.1:8788`.
4. Unlock the public institution through a qualifying access route or use the clearly labelled local QA route.
5. Open **Training Toolkit Ω**.
6. Select **Proof-Capital Mission Alpha Planning** for the clearest synthetic example.
7. Select **Compile institution**.
8. Select **Run protected cycle**.
9. Review the candidate table, exact release commitment, verifier report, Proof-Adjusted Alpha and Chronicle lineage.
10. Download the complete run record.

## Command-line route

```bash
cd alpha-foundry
python -m goalos_alpha_foundry.cli catalog
python -m goalos_alpha_foundry.cli inspect --mission mission_alpha_planning
python -m goalos_alpha_foundry.cli cycle \
  --mission mission_alpha_planning \
  --formation 120 --fresh 80 --transfer 40 \
  --out toolkit_cycle.json
```

## What a PASS means

`SPECIALIST_ASI_GATE_SIMULATION_PASS` means one exact reference candidate passed the disclosed synthetic mission gate. It is not a claim that a real external Specialist ASI exists. No authority is created.
