# Security, access and authority

The public access rule is unchanged:

**Access = current direct AGI Club owner OR current direct holder of at least 1,000,000 official AGIALPHA on Ethereum Mainnet.**

Qualifying token contract:

`0xA61a3B3a130a9c20768EEBF97E21515A6046a1fA`

The app requests no token approval, transfer, payment, deposit, staking, locking, burning or custody. A signed access receipt records `authorityCreated: NONE`.

Access does not establish identity assurance, competence, professional authority, organizational mandate, Specialist ASI status, Chronicle admission or successor authority.

The local Foundry is intended for controlled use. A public production deployment should place the training backend behind the access-revalidating gateway, HTTPS, exact CORS, a private network and organizational authorization.
