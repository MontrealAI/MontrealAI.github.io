# GoalOS v8.0.0-UVSI3 — Three-minute quick start

## Route A — Open the public GitHub Pages product

1. Deploy the GitHub Pages ZIP.
2. Connect a wallet on Ethereum Mainnet.
3. Qualify through current direct AGI Club ownership or a current direct balance of at least 1,000,000 official AGIALPHA.
4. Open **Algorithm Router** and select a mission.
5. Click **Compile portfolio**.
6. Open **Alpha Foundry Ω**.
7. Click **Run browser tournament** for an immediate deterministic demonstration.

The browser tournament is a portfolio simulator. It is intentionally labelled as such.

## Route B — Run executable local training

1. Unzip the Local Foundry package.
2. Double-click `START_MAC.command`, `START_WINDOWS.bat`, or `START_LINUX.sh`.
3. A local page opens at `http://127.0.0.1:8788`.
4. Use the local QA access route, open **Algorithm Router**, compile the portfolio, then select **Run executable backend**.
5. Download the tournament record.

The local backend requires only Python 3.10 or newer and no third-party package.

## How to read the result

- **Fresh quality**: accepted mission result rate on unseen cases.
- **Evidence**: average source/evidence coverage.
- **Critical / Unauthorized**: hard-gate failures; any non-zero result blocks promotion.
- **LCB gain**: conservative lower confidence bound versus the best reference.
- **Proof-adjusted α**: residual advantage after cost, complexity, Proof Debt, transfer reserve and Gym-to-reality basis risk.
- **Champion**: highest positive Alpha among hard-gate passers; otherwise the best reference.

Importing the champion into the main application creates a candidate only. It inherits neither proof nor authority.
